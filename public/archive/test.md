## **1. Core Concepts of Microservices**  
**What to Learn:**  
- Definition: Microservices vs. Monolith vs. SOA  
- Benefits: Scalability, Independent Deployment, Tech Diversity  
- Challenges: Distributed Systems Complexity, Network Latency, Data Consistency  
- When to use (and when **not** to use) microservices  

**Resources:**  
- [Martin Fowler’s Microservices Guide](https://martinfowler.com/microservices/)  
- [Microservices – Amazon’s Approach](https://aws.amazon.com/microservices/)  

## **2. API Design & Communication**  
**What to Learn:**  
- **RESTful APIs** (HTTP methods, status codes, HATEOAS)  
- **gRPC** (Protocol Buffers, high-performance RPC)  
- **GraphQL** (Alternative to REST for flexible queries)  
- API Documentation (OpenAPI/Swagger)  
- API Gateways (Kong, AWS API Gateway)  

**Hands-On:**  
- Build 3 services (User, Product, Order) with REST & gRPC.  
- Use Postman/Insomnia for testing.  

**Resources:**  
- [REST API Best Practices](https://www.freecodecamp.org/news/rest-api-best-practices/)  
- [gRPC Official Docs](https://grpc.io/)  

## **3. Containers & Orchestration**  
**What to Learn:**  
- **Docker** (Containerization, Dockerfiles, Docker Compose)  
- **Kubernetes (K8s)** (Pods, Deployments, Services, Ingress)  
- **Service Discovery** (Consul, Eureka)  
- **Load Balancing**  

**Hands-On:**  
- Containerize your services with Docker.  
- Deploy locally using `minikube` or `k3s`.  

**Resources:**  
- [Docker Get Started](https://docs.docker.com/get-started/)  
- [Kubernetes Basics](https://kubernetes.io/docs/tutorials/kubernetes-basics/)
